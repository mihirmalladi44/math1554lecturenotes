    \({\LARGE \textbf{1.1 Block Matrices}}\)
    A block matrix is a matrix that is interpreted as having been broken into sections called blocks, or submatrices. Intuitively, a block matrix can be interpreted as the original matrix that is partitioned into a collection of smaller matrices. For example, the matrix
    🔗
    \begin{equation*} A = \begin{pmatrix} 1 \amp 1 \amp 1 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 1 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 2 \amp 2 \amp 2 \end{pmatrix} \end{equation*}
    can also be written as a 2 × 2 partitioned (or block) matrix:
    🔗
    \begin{equation*} A = \begin{pmatrix} A_{1,1} \amp A_{1,2} \\ A_{2,1} \amp A_{2,2} \end{pmatrix} \end{equation*}
    where the entries of A are the blocks
    🔗
    \begin{equation*} A_{1,1} = \begin{pmatrix} 1 \amp 1 \\ 1 \amp 1 \\ 1 \amp 1 \end{pmatrix} \quad A_{1,2} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \quad A_{2,1} = \begin{pmatrix} 0 \amp 0 \end{pmatrix} \quad A_{2,2} = \begin{pmatrix} 2 \amp 2 \amp 2 \end{pmatrix} \end{equation*}
    We partitioned our matrix into four blocks, each of which have different dimensions. But the matrix could also, for example, be partitioned into five 4 × 1 blocks, or four 1 × 5 blocks. Indeed, matrices can be partitioned into blocks in many different ways, and depending on the application at hand, there can be a partitioning that is useful or needed.
    🔗
    For example, when solving a linear system \(A\vec{x} = \vec{b}\) to determine \(\vec{x}\text{,}\) we can construct and row reduce an augmented matrix of the form
    🔗
    \begin{equation*} X = \begin{pmatrix} A \amp \vec{b} \end{pmatrix} \end{equation*}
    The augmented matrix X consists of two sub-matrices, A and \(\vec{b}\text{,}\) meaning that it can be viewed as a block matrix. Another application of a block matrix arises when using the SVD, which is a popular tool used in data science. The SVD uses a matrix, \(\Sigma\text{,}\) of the form
    🔗
    \begin{equation*} \Sigma = \begin{pmatrix} D \amp \mathbf{0} \\ \mathbf{0} \amp \mathbf{0} \end{pmatrix} \end{equation*}
    Matrix D is a diagonal matrix, and each \(\mathbf{0}\) is a zero matrix. Representing \(\Sigma\) in terms of sub-matrices helps us see what the structure of \(\Sigma\) is. Another block matrix arises when introducing a procedure for computing the inverse of an \(n \times n\) matrix. To compute the inverse of matrix A, we construct and row reduce the matrix
    🔗
    \begin{equation*} X = \begin{pmatrix} A \amp I \end{pmatrix} \end{equation*}
    This is an example of a block matrix used in an algorithm. In order to use block matrices in other applications we need to define matrix addition and multiplication with partitioned matrices.
    🔗
    \({\large \textbf{1.1.1 Block Matrix Addition}}\)
    If \(m \times n\) matrices A and B are partitioned in exactly the same way, then the entries of their sum is the sum of their blocks. For example, if A and B are the block matrices
    🔗
    \begin{equation*} A = \begin{pmatrix} A_{1,1} \amp A_{1,2} \\ A_{2,1} \amp A_{2,2} \end{pmatrix}, \quad B = \begin{pmatrix} B_{1,1} \amp B_{1,2} \\ B_{2,1} \amp B_{2,2} \end{pmatrix} \end{equation*}
    then their sum is the matrix
    🔗
    \begin{equation*} A + B = \begin{pmatrix} A_{1,1} + B_{1,1} \amp A_{1,2} + B_{1,2} \\ A_{2,1} + B_{2,1} \amp A_{2,2} + B_{2,2} \end{pmatrix} \end{equation*}
    As long as A and B are partitioned in the same way the addition is calculated block by block.
    🔗
    \({\large \textbf{1.1.2 Block Matrix Multiplication}}\)
    Recall the row column method for matrix multiplication.
    🔗
    \({\large \textbf{Theorem}}\)
    Let \(A\) be \(m \times n\) and \(B\) be \(n \times p\) matrix. Then, the \((i, j)\) entry of \(AB\) is
    🔗
    \begin{equation*} \operatorname{row}_i(A) \cdot \operatorname{col}_j(B). \end{equation*}
    This is the Row Column Method for matrix multiplication.
    🔗
    Partitioned matrices can be multiplied using this method, as if each block were a scalar provided each block has appropriate dimensions so that products are defined.
    🔗
    \({\large \textbf{1.1.3 Example 1: Computing }A^2}\)
    Block matrices can be useful in cases where a matrix has a particular structure.
    🔗
    For example, suppose \(A\) is the \(n \times n\) block matrix
    🔗
    \begin{equation*} A = \begin{pmatrix} X \amp \mathbf{0} \\ \mathbf{0} \amp Y \end{pmatrix} \end{equation*}
    where \(X\) and \(Y\) are \(p \times p\) matrices, \(\mathbf{0}\) is a \(p \times p\) zero matrix, and \(2p = n\text{.}\) Then
    🔗
    \begin{equation*} A^2 = AA = \begin{pmatrix} X \amp \mathbf{0} \\ \mathbf{0} \amp Y \end{pmatrix} \begin{pmatrix} X \amp \mathbf{0} \\ \mathbf{0} \amp Y \end{pmatrix} = \begin{pmatrix} X^2 \amp \mathbf{0} \\ \mathbf{0} \amp Y^2 \end{pmatrix} \end{equation*}
    Computation of \(A^2\) only requires computing \(X^2\) and \(Y^2\text{.}\) Taking advantage of the block structure \(A\) leads to a more efficient computation than it otherwise would have been with a naive row-column method that does not take advantage of the structure of the matrix.
    🔗
    \({\large \textbf{1.1.4 Example 2: Computing }AB}\)
    \(A\) and \(B\) are the matrices
    🔗
    \begin{equation*} A = \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \end{pmatrix} = \begin{pmatrix} A_{11} \amp A_{12} \end{pmatrix} \qquad B = \begin{pmatrix} 2 \amp -1 \\ 0 \amp -1 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} B_{11} \\ B_{21} \end{pmatrix} \end{equation*}
    where
    🔗
    \begin{equation*} A_{11} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}, \quad A_{12} = \begin{pmatrix} 1 \\ 1 \end{pmatrix}, \quad B_{11} = \begin{pmatrix} 2 \amp -1 \\ 0 \amp -1 \end{pmatrix}, \quad B_{21} = \begin{pmatrix} 0 \amp 1 \end{pmatrix} \end{equation*}
    If we compute the matrix product using the given partitioning we obtain
    🔗
    \begin{equation*} AB = \begin{pmatrix} A_{11} \amp A_{12} \end{pmatrix} \begin{pmatrix} B_{11} \\ B_{21} \end{pmatrix} = \begin{pmatrix} A_{11}B_{11} + A_{12}B_{21} \end{pmatrix} \end{equation*}
    where
    🔗
    \begin{equation*} A_{11}B_{11} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix} \begin{pmatrix} 2 \amp -1 \\ 0 \amp -1 \end{pmatrix} = \begin{pmatrix} 2 \amp -1 \\ 0 \amp -1 \end{pmatrix} \qquad A_{12}B_{21} = \begin{pmatrix} 1 \\ 1 \end{pmatrix} \begin{pmatrix} 0 \amp 1 \end{pmatrix} = \begin{pmatrix} 0 \amp 1 \\ 0 \amp 1 \end{pmatrix} \end{equation*}
    Therefore
    🔗
    \begin{equation*} AB = A_{11}B_{11} + A_{12}B_{21} = \begin{pmatrix} 2 \amp -1 \\ 0 \amp -1 \end{pmatrix} + \begin{pmatrix} 0 \amp 1 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 0 \end{pmatrix} \end{equation*}
    Computing \(AB\) with the row column method confirms our result.
    🔗
    \begin{equation*} AB = \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \end{pmatrix} \begin{pmatrix} 2 \amp -1 \\ 0 \amp -1 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} 2 + 0 + 0 \amp -1 + 0 + 1 \\ 0 + 0 + 0 \amp 0 - 1 + 1 \end{pmatrix} = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 0 \end{pmatrix} \end{equation*}
    \({\large \textbf{1.1.5 Block Matrix Inversion}}\)
    In some cases, matrix partitioning can be used to give us convenient expressions for the inverse of a matrix. Recall that the inverse of \(n \times n\) matrix \(A\) is a matrix \(B\text{,}\) that has the same dimensions as \(A\) and satisfies
    🔗
    \begin{equation*} AB = BA = I \end{equation*}
    where \(I\) is the \(n \times n\) identity matrix. As we will see in the next example, we can use this equation to construct expressions for the inverse of a matrix.
    🔗
    \({\large \textbf{1.1.6 Example 3: Expression for Inverse of a Block Matrix}}\)
    Recall, using our formula for a 2 × 2 matrix,
    🔗
    \begin{equation*} \begin{pmatrix} a \amp b \\ 0 \amp c \end{pmatrix}^{-1} = \frac{1}{ac} \begin{pmatrix} c \amp -b \\ 0 \amp a \end{pmatrix} = \begin{pmatrix} 1/a \amp -b/(ac) \\ 0 \amp 1/c \end{pmatrix} \quad \quad \quad \text{(1.1)} \end{equation*}
    provided that \(ac \neq 0\text{.}\) Suppose \(A\text{,}\) \(B\text{,}\) and \(C\) are invertible \(n \times n\) matrices. Suppose we wish to construct an expression for the inverse of the matrix
    🔗
    \begin{equation*} P = \begin{pmatrix} A \amp B \\ \mathbf{0} \amp C \end{pmatrix} \end{equation*}
    To construct the inverse of \(P\text{,}\) we can write
    🔗
    \begin{equation*} PP^{-1} = P^{-1}P = I_n \end{equation*}
    where \(P^{-1}\) is the matrix we seek. If we let \(P^{-1}\) be the block matrix
    🔗
    \begin{equation*} P^{-1} = \begin{pmatrix} W \amp X \\ Y \amp Z \end{pmatrix} \end{equation*}
    we can determine \(P^{-1}\) by solving \(PP^{-1} = I_n\) or \(P^{-1}P = I_n\text{.}\) Solving \(PP^{-1} = I_n\) gives us:
    🔗
    \begin{equation*} I_n = PP^{-1} = \begin{pmatrix} I \amp \mathbf{0} \\ \mathbf{0} \amp I \end{pmatrix} = \begin{pmatrix} A \amp B \\ \mathbf{0} \amp C \end{pmatrix} \begin{pmatrix} W \amp X \\ Y \amp Z \end{pmatrix} \end{equation*}
    \begin{equation*} \begin{pmatrix} I \amp \mathbf{0} \\ \mathbf{0} \amp I \end{pmatrix} = \begin{pmatrix} AW + BY \amp AX + BZ \\ CY \amp CZ \end{pmatrix} \end{equation*}
    The above matrix equation gives us a set of four equations that can be solved to determine \(W\text{,}\) \(X\text{,}\) \(Y\text{,}\) and \(Z\text{.}\) The block in the second row and first column gives us \(CY = \mathbf{0}\text{.}\) It was given that \(C\) is an invertible matrix, so \(Y\) is a zero matrix because
    🔗
    \begin{equation*} CY = \mathbf{0} \end{equation*}
    \begin{equation*} C^{-1}CY = C^{-1}\mathbf{0} \end{equation*}
    \begin{equation*} IY = \mathbf{0} \end{equation*}
    \begin{equation*} Y = \mathbf{0} \end{equation*}
    Likewise the block in the second row and second column yields \(CZ = I\text{,}\) so
    🔗
    \begin{equation*} CZ = I \end{equation*}
    \begin{equation*} C^{-1}CZ = C^{-1}I \end{equation*}
    \begin{equation*} Z = C^{-1} \end{equation*}
    Now that we have expressions for \(Y\) and \(Z\) we can solve the remaining two equations for \(W\) and \(X\text{.}\) Solving for \(X\) gives us the following expression.
    🔗
    \begin{equation*} AX + BZ = \mathbf{0} \end{equation*}
    \begin{equation*} AX + BC^{-1} = \mathbf{0} \end{equation*}
    \begin{equation*} AX = -BC^{-1} \end{equation*}
    \begin{equation*} A^{-1}AX = -A^{-1}BC^{-1} \end{equation*}
    \begin{equation*} X = -A^{-1}BC^{-1} \end{equation*}
    Solving for \(W\text{:}\)
    🔗
    \begin{equation*} AW + BY = I \end{equation*}
    \begin{equation*} AW + B\mathbf{0} = I \end{equation*}
    \begin{equation*} A^{-1}AW = A^{-1}I \end{equation*}
    \begin{equation*} W = A^{-1} \end{equation*}
    We now have our expression for \(P^{-1}\text{:}\)
    🔗
    \begin{equation*} P^{-1} = \begin{pmatrix} W \amp X \\ Y \amp Z \end{pmatrix} = \begin{pmatrix} A^{-1} \amp -A^{-1}BC^{-1} \\ \mathbf{0} \amp C^{-1} \end{pmatrix} \end{equation*}
    Note that in the special case where \(n = 2\) that each of the blocks are scalars and our expression is equivalent to Equation (1.1).
    🔗
    \({\large \textbf{1.1.7 Summary}}\)
    In this section we used partitioned matrices to solve problems regarding matrix invertibility and matrix multiplication. Partitioned matrices can be multiplied using this method, as if each block were a scalar provided each block has appropriate dimensions so that products are defined. They can be used for example when dealing with large matrices that have a known structure where it is more convenient to describe the structure of a matrix in terms of its blocks. Although not part of this text, matrix partitioning can be used to help derive new algorithms because they give a more concise representation of a matrix and of operations on matrices.
