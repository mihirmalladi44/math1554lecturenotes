    Section 2.7 Applications of The SVD

    The SVD has been applied to many modern applications in CS, engineering, and mathematics. In this section we will use the SVD to construct bases for the four fundamental subspaces of a matrix, characterize how errors in the entires of \(A\) could lead to errors when solving \(A\vec x = \vec b\text{,}\) and construct a spectral decomposition of a matrix.
    🔗

    Subsection The Condition Number of a Matrix

    In some applications of linear algebra, entries of \(A\) and contain errors. The condition number of a matrix describes the sensitivity that any approach to determining solutions to \(A\vec x = \vec b\) might have to errors in \(A\text{.}\) These errors could arise from the way the entries of \(A\) are stored, or from the way that the entries of \(A\) were determined.
    🔗

    Definition 37.

    Suppose \(A\) is an invertible \(n\times n\) matrix. The ratio
    🔗
    \begin{equation*} \kappa = \frac{\sigma_1}{\sigma_n} \end{equation*}
    is the condition number of \(A\text{,}\) where \(\sigma_1\) is the largest singular value of \(A\text{,}\) and \(\sigma_n\) is the smallest.
    🔗
    🔗
    The larger the condition number, the more sensitive the system is to errors.
    🔗

    Subsubsection Example 1: The Condition Number of a \(2\times2\) Matrix

    Suppose \(A = \begin{pmatrix}2 \amp -1\\2 \amp 1\end{pmatrix}\text{.}\) We found in an earlier example that \(\sigma_1 = \sqrt8, \sigma_2 = \sqrt2\text{.}\) Therefore, the condition number of \(A\) is
    🔗
    \begin{equation*} \kappa = \frac{\sigma_1}{\sigma_n} = \frac{\sqrt8}{\sqrt2}=2 \end{equation*}
    🔗

    Subsubsection Example 2: The Condition Number of a Matrix with Orthogonal Columns

    Suppose \(h>0\) is any positive real number and \(A\) is the matrix
    🔗
    \begin{equation*} A = \begin{pmatrix} 2 \amp h \amp 1 \\ 1 \amp 0 \amp -4 \\ 2 \amp -h \amp 1 \end{pmatrix} \end{equation*}
    This matrix happens to have orthogonal columns, so \(A^TA\) will be diagonal.
    🔗
    \begin{equation*} A^TA = \begin{pmatrix} 9\amp0\amp0\\0\amp2h^2\amp0\\0\amp0\amp18\end{pmatrix} \end{equation*}
    Then by inspection the eigenvalues of \(A^TA\) are \(18, 9\) and \(2h^2\text{.}\) If \(h\) is a small positive number close to zero, the condition number is the ratio
    🔗
    \begin{equation*} \kappa = \frac{\sigma_1}{\sigma_3}=\frac{\sqrt{18}}{\sqrt{2h^2}} = \frac3h \end{equation*}
    As \(h\) tends to zero \(\sigma_3\) also tends to zero, and \(\kappa\) tends to infinity. This suggests that when \(h\) is very small, the process of solving the linear system \(A\vec x = \vec b\) would be sensitive to any errors made in calculating the solution. And that there could be a relationship between how close \(A\) is to a singular matrix and the sensitivity to errors in calculating the solution to \(A\vec x = \vec b\text{.}\) A more detailed discussion would certainly go beyond the scope of our discussion.
    🔗
    🔗
    🔗

    Subsection The SVD and the Four Fundamental Subspaces

    Suppose \(\vec v_i\) are orthonormal eigenvectors for \(A^TA\text{,}\) and
    🔗
    \begin{equation*} \vec u _i = \frac{1}{\sigma_i}A\vec v_ i \ \text{ for } i \le r = \Rank A, \ \sigma_i = \lVert A \vec v_i \rVert. \end{equation*}
    Then we have the following bases for any \(m\times n\) real matrix \(A\text{.}\)
    🔗
    • \(\vec v_1 ,\dotsc, \vec v_r\) is an orthonormal basis for \(\textup{Row} A\text{.}\)
      🔗
      🔗
    • \(\vec v_{r+1} ,\dotsc, \vec v_n\) is an orthonormal basis for \(\Nul A\text{.}\)
      🔗
      🔗
    • \(\vec u_1 ,\dotsc, \vec u_r\) is an orthonormal basis for \(\textup{Col} A\text{.}\)
      🔗
      🔗
    • \(\vec u_{r+1} , \dotsc , \vec u_m\) is an orthonormal basis for \(\textup{Col} A^{\perp} = \Nul A^T\text{.}\)
      🔗
      🔗

    Subsubsection Example 3: Constructing Orthonormal Bases for the Fundamental Subspaces

    Suppose \(A\) is a \(4\times 5\) matrix whose SVD is given below.
    🔗
    \begin{equation*} A = U \Sigma V^T = \begin{pmatrix} 0 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 1 \amp 0\\ 0 \amp 0 \amp 0 \amp -1\\ -1 \amp 0 \amp 0 \amp 0 \end{pmatrix} \begin{pmatrix} 5 \amp 0 \amp 0 \amp 0 \amp 0\\ 0 \amp 3 \amp 0 \amp 0 \amp 0\\ 0 \amp 0 \amp 2 \amp 0 \amp 0\\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \begin{pmatrix} 0 \amp 0 \amp \sqrt{0.8} \amp 0 \amp -\sqrt{0.2}\\ 1 \amp 0 \amp 0 \amp 0 \amp 0\\ 0 \amp 1 \amp 0 \amp 0 \amp 0\\ 0 \amp 0 \amp 0 \amp 1 \amp 0\\ 0 \amp 0 \amp \sqrt{0.8} \amp 0 \amp \sqrt{0.2} \end{pmatrix} \end{equation*}
    There are exactly three non-zero singular values, so \(r = \Rank A = 3\text{.}\) The first three columns of \(V\) are a basis for \(\Row A\) and the last two columns of \(V\) (or rows of \(V^T\)) are a basis for \(\Nul A\text{.}\) The first three columns of \(U\) are a basis for \(\Col A\text{,}\) and the remaining column of \(U\) are a basis for \((\Col A)^{\perp}\text{.}\)
    🔗
    🔗
    🔗

    Subsection The Spectral Decomposition of a Matrix

    The SVD can be also used to approximate any \(m\times n\) real matrix with what is defined as the spectral decomposition. Note that a similar decomposition for symmetric matrices that uses the orthogonal decomposition of a matrix is described in Appendix 3.2.
    🔗

    Spectral Decomposition.

    For any real \(m\times n\) matrix \(A\) with rank \(r\) and SVD \(A= U \Sigma V^T\) we can write
    🔗
    \begin{equation*} A = U\Sigma V^T = \sum_{i=1} ^{r} \sigma _i \vec u _{i} \vec v _{i}\, ^{T} = \sigma_1 \vec u_1 \vec v_1^T + \sigma_2 \vec u_2 \vec v_2^T + \ldots + \sigma_r \vec u_r \vec v_r^T \end{equation*}
    Vectors \(\vec u_i, \vec v_i\) are the \(i^{th}\) columns of \(U\) and \(V\) respectively.
    🔗
    🔗
    Here we give a short explanation on why \(A\) has the decomposition
    🔗
    \begin{equation*} A = \lambda _1 \vec u_1 \vec u_1 ^{T} + \cdots + \lambda _n \vec u_n \vec u_n ^{T} = \sum_{i=1}^{n} \lambda_i \vec u_i \vec u_i^T \end{equation*}
    If the columns of \(\Sigma\) are \(\vec s_1, \vec s_2, \cdots , \vec s_n\text{,}\) then, using the definition of matrix multiplication,
    🔗
    \begin{equation*} U\Sigma = U\begin{pmatrix} \vec s_1 \amp \vec s_2 \amp \cdots \amp \vec s_n\end{pmatrix} = \begin{pmatrix} U\vec s_1 \amp U \vec s_2 \amp \cdots \amp U\vec s_n\end{pmatrix} \end{equation*}
    Recall that a matrix times a vector is a linear combination of the columns of the matrix weighted by the entries of the vector. Column \(i\) of the product \(U\Sigma\) is
    🔗
    \begin{equation*} U\Sigma _i = U\begin{pmatrix} 0\\ \vdots\\ 0\\ \lambda_i\\ 0\\ \vdots \end{pmatrix} = 0+0+\ldots +0 +\lambda_i \vec u_i+0 + \ldots =\lambda_i \vec u_i \end{equation*}
    Therefore, the columns of \(PD\) are \(\lambda_i \vec u_i\text{.}\) We can now simplify our expression for \(A=PDP^T\) to a product of two \(n \times n\) matrices. \(A\) can be expressed as
    🔗
    \begin{equation*} A = U\Sigma V^T = \begin{pmatrix} \sigma_1 \vec u_1 \amp \sigma_2 \vec u_2 \amp \cdots \amp \sigma_n \vec u_n \end{pmatrix} \begin{pmatrix} \vec v_1 ^{T} \\ \vec v_2^T \\ \vdots \\ \vec v_n ^{T} \end{pmatrix} \end{equation*}
    Using the column-row expansion for the product of two matrices, this becomes
    🔗
    \begin{equation*} A = \sigma _1 \vec u_1 \vec v_1 ^{T} + \cdots + \sigma _n \vec u_n \vec v_n ^{T} = \sum_{i=1}^{n} \sigma_i \vec u_i \vec v_i^T \end{equation*}
    The row-column expansion for the product of two matrices is a way of defining matrix multiplication. Note that each term in this sum is a rank 1 matrix. In applications of linear algebra, \(\sigma_i\) can become sufficiently small, allowing us to approximate \(A\) with a small number of rank 1 matrices.
    🔗

    Subsubsection Example 4: The Spectral Decomposition of a \(4\times 2\) Matrix

    Suppose \(A\) has the following SVD.
    🔗
    \begin{equation*} A = \begin{pmatrix} 2 \amp 0 \\ 0 \amp -3 \\ 0 \amp 0 \\ 0 \amp 0 \end{pmatrix} = \begin{pmatrix} 0 \amp 1 \amp 0 \amp 0\\ -1 \amp 0 \amp 0 \amp 0\\ 0 \amp 0 \amp 1 \amp 0\\ 0 \amp 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 3 \amp 0\\ 0 \amp 2\\ 0 \amp 0\\ 0 \amp 0 \end{pmatrix} \begin{pmatrix} 0 \amp 1\\ 1 \amp 0 \end{pmatrix} \end{equation*}
    The spectral decomposition of \(A\) is as follows.
    🔗
    \begin{equation*} A = \sum_{s=1} ^{r} \sigma _s \vec u _{s} \vec v _{s} ^{T} \end{equation*}
    \begin{equation*} = 3 \begin{pmatrix} 0\\ -1\\ 0\\ 0 \end{pmatrix} \begin{pmatrix} 0 \amp 1 \end{pmatrix} + 2 \begin{pmatrix} 1\\ 0\\ 0\\ 0 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \end{pmatrix} \end{equation*}
    \begin{equation*} = 3 \begin{pmatrix} 0 \amp 0\\ 0 \amp -1\\ 0 \amp 0\\ 0 \amp 0 \end{pmatrix} + 2 \begin{pmatrix} 1 \amp 0\\ 0 \amp 0\\ 0 \amp 0\\ 0 \amp 0 \end{pmatrix} \end{equation*}
    🔗

    Subsubsection Example 5: The Spectral Decomposition of a \(4\times5\) Matrix

    In this example we construct and discuss the spectral decomposition of the \(4\times 5\) matrix
    🔗
    \begin{equation*} A = \begin{pmatrix} 1 \amp -2 \amp 2 \amp -2 \amp -4 \\ 0 \amp 2 \amp 0 \amp 2 \amp 4 \\ 2 \amp 1 \amp 4 \amp 1 \amp 2\\ 2 \amp 0 \amp 4 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    With some help from MATLAB we obtain the eigenvalues of \(A^TA\) and the singular values of \(A\text{.}\)
    🔗
    \begin{equation*} \lambda_1 = 54 \quad \Rightarrow \quad \sigma_1 = \sqrt{54} = 3 \sqrt{6}\approx 7.3485 \end{equation*}
    \begin{equation*} \lambda_2 = 45 \quad \Rightarrow \quad \sigma_2 = \sqrt{45} = 3 \sqrt{5} \approx 6.7082 \end{equation*}
    The script used to compute the eigenvalues are below.
    🔗
    \begin{equation*} \vec u_1 = \frac13\begin{pmatrix} 2\\-2\\-1\\0\end{pmatrix}, \quad \vec u_2 = \frac13 \begin{pmatrix}-1\\0\\-2\\-2 \end{pmatrix}, \quad \vec v_1 = \frac{1}{\sqrt6}\begin{pmatrix} 0\\-1\\0\\-1\\-2\end{pmatrix}, \quad \vec v_2 = \frac{1}{\sqrt5}\begin{pmatrix} -1\\0\\-2\\0\\0\end{pmatrix} \end{equation*}
    The MATLAB script that computes the eigenvalues of \(A^TA\) and the SVD of \(A\) is shown below.
    🔗

    MATLAB Script.

    A = [1 -2 2 -2 -4;0 2 0 2 4;2 1 4 1 2;2 0 4 0 0];
AA = A'*A;  % compute A^TA
L = eig(AA); % L will be a vector containing the eigenvalues of A^TA
[U,S,V] = svd(A); % this will give us the SVD of matrix A
    🔗
    Using the SVD of \(A\) we can construct the spectral decomposition of \(A\) is as follows. Note that in this case that the number of non-zero singular values is \(r=\Rank A = 2\text{.}\)
    🔗
    \begin{equation*} A = \sum_{s=1} ^{r} \sigma _s \vec u _{s} \vec v _{s} ^{T} \end{equation*}
    \begin{equation*} = \sigma_1 \vec u_1 \vec v_1^T + \sigma_2 \vec u_2 \vec v_2^T \end{equation*}
    \begin{equation*} = \frac{3\sqrt{6}}{3\sqrt{6}} \begin{pmatrix} 2\\ -2\\ -1\\ 0 \end{pmatrix} \begin{pmatrix} 0 \amp -1 \amp 0 \amp -1 \amp -2 \end{pmatrix} + \frac{3\sqrt{5}}{3\sqrt{5}} \begin{pmatrix} -1\\ 0\\ -2\\ -2 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \end{pmatrix} \end{equation*}
    \begin{equation*} = \begin{pmatrix} 2\\ -2\\ -1\\ 0 \end{pmatrix} \begin{pmatrix} 0 \amp -1 \amp 0 \amp -1 \amp -2 \end{pmatrix} + \begin{pmatrix} -1\\ 0\\ -2\\ -2 \end{pmatrix} \begin{pmatrix} -1 \amp 0 \amp -2 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    Notice how this representation of \(A\) only requires two vectors with four entries and two vectors with 5 entries each, for a total of 18 numbers. The original matrix is \(4\times 5\text{,}\) which requires 20 numbers. The spectral decomposition happened to give us a slightly more concise representation of \(A\text{.}\) But we were only able to obtain this result because there a few non-zero singular values. Had there been three or four non-zero singular singular values, the spectral decomposition would have not been as concise. More generally, the reduction in the amount of data needed to represent a matrix will be greater with larger matrices that also have a small number of non-zero singular values.
    🔗
    🔗
    🔗

    Subsection Summary

    In this section we introduced three applications of the SVD and singular values.
    🔗
    • The four fundamental subspaces of a matrix can be calculated using the left and right singular vectors.
      🔗
      🔗
    • The condition number of a square invertible matrix, \(\kappa = \frac{\sigma_1}{\sigma_n}\text{,}\) characterizes the sensitivity to solving \(A\vec x = \vec b\) to errors in \(A\text{.}\)
      🔗
      🔗
    • The spectral decomposition of a matrix can be calculated using its SVD.
      🔗
      🔗
    A similar decomposition for symmetric matrices that uses the orthogonal decomposition of a matrix is described in Appendix 3.2.
    🔗
    While there are numerous applications of the SVD, many of them would be beyond the scope of this course and would require introducing topics and problems that would go beyond the scope of a linear algebra course.
