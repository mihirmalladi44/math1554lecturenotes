    Section 1.4 2D Computer Graphics

    Linear transformations are often used in computer graphics to simulate the motion of an object. They can be modeled with a matrix-vector product of the form
    \begin{equation*} T(\vec x) = A\vec x \end{equation*}
    where \(\vec x\) is a vector that represents a point that is transformed to the vector \(A\vec x\text{.}\) The matrix-vector product \(A\vec x\) is a transformation that acts on the vector \(\vec x\) to produce a new vector, \(\vec b = A\vec x\text{,}\) and if we set the function \(T(\vec x)\) to be
    \begin{equation*} T(\vec x) = A\vec x = \vec b \end{equation*}
    then \(T\) maps the vector \(\vec x\) to vector \(\vec b\text{.}\) The nature of the transform is described by matrix \(A\text{.}\)
    🔗
    Translations are a type of transformation needed in computer graphics. But translations are not a linear transformation because they do not leave the origin fixed. How might we use matrix multiplication in order to perform such transformations? In this section we answer this question by introducing homogeneous coordinates, which allow for more general transformations to be computed with linear algebra.
    🔗

    Subsection Homogeneous Coordinates

    Homogeneous coordinates are a tool that can be used to model translations.
    🔗

    Definition: Homogeneous Coordinates in \(\R^2\).

    Each point \((x,y)\) in \(\R^2\) can be identified with the point \((x,y,1)\text{,}\) on the plane in \(\R^3\) that lies \(1\) unit above the \(xy\)-plane.
    🔗
    🔗
    For example, a translation of the form \((x,y) \to (x+h,y+k)\) is a transformation. The parameters \(h\) and \(k\) adjust the location of the point \((x,y)\) after the transformation. This transform can be represented as a matrix multiplication with homogeneous coordinates in the following way.
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp h \\ 0 \amp 1 \amp k \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} x\\y\\1 \end{pmatrix} = \begin{pmatrix} x+h\\y+k\\1 \end{pmatrix} \end{equation*}
    The first two entries can be extracted from the output of the transform to obtain the coordinate of the translated point. The following examples demonstrate how homogeneous coordinates can be used to create more general transforms.
    🔗
    🔗

    Subsection Example 1: A Composite Transform with Translation

    Suppose the transformation \(T(\vec x)\) reflects points in \(\R^2\) across the line \(x_2 = x_1\) and then translates them by \(2\) units in the \(x_1\) direction and \(3\) units in the \(x_2\) direction. In this example we will use homogeneous coordinates to construct a matrix \(A\) so that \(T = A\vec x\text{.}\)
    🔗
    With homogeneous coordinates the point \((x,y)\) may be represented by the vector
    \begin{equation*} \begin{pmatrix} x\\y\\1 \end{pmatrix} \end{equation*}
    Points in \(\R^2\) can be reflected across the line \(x_2 = x_1\) using the standard matrix
    \begin{equation*} A_r = \begin{pmatrix} 0 \amp 1 \\ 1 \amp 0 \end{pmatrix} \end{equation*}
    With homogeneous coordinates our point is represented with a vector in \(\R^3\text{,}\) so we use the block matrix
    \begin{equation*} A_1 = \begin{pmatrix} A_r \amp \textbf{0} \\ \textbf{0} \amp 1 \end{pmatrix} = \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    The symbol \(\textbf{0}\) denotes a matrix of zeroes. In this case, either a \(1\times2\) matrix or a \(2\times1\) matrix. Then the matrix-vector product below produces the needed transformation.
    \begin{equation*} A_1 \vec x = \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} x\\y\\1 \end{pmatrix} = \begin{pmatrix} y \\x\\1 \end{pmatrix} \end{equation*}
    Note that the \(x_1\) and \(x_2\) coordinates have been swapped, as required for the reflection through the line \(x_2 = x_1\text{.}\) The matrix below will perform the translation we need.
    \begin{equation*} A_2 = \begin{pmatrix} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    The product below will apply the translation, of \(2\) units in the \(x_1\) direction and \(3\) units in the \(x_2\) direction, to the reflected point.
    \begin{equation*} T(\vec x) = A_2 (A_1 \vec x) = A_2 A_1 \vec x = \begin{pmatrix} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} y \\x\\1 \end{pmatrix} = \begin{pmatrix} y +2 \\x + 3\\1 \end{pmatrix} \end{equation*}
    Therfore, our standard matrix is
    \begin{align*} A = A_2A_1 \amp = \begin{pmatrix} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \amp = \begin{pmatrix} 0 \amp 1 \amp 2 \\ 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    🔗
    🔗

    Subsection Example 2: Rotation About the Point \(\mathbf{(0,1)}\)

    Triangle \(S\) is determined by the points \((1,1), (2,3), (3,1)\text{.}\) Transform \(T\) rotates these points by \(\pi/2\) radians counterclockwise about the point \((0,1)\text{.}\) Our goal is to use matrix multiplication to determine the image of \(S\) under \(T\text{.}\)
    🔗
    A sketch of the triangle before and after the rotation is in the diagram below.
    🔗
    We need a way to calculate the locations of the points after the transformation. The rotation can be calculated by first representing each point by a vector in homogeneous coordinates, and then multiplying the vectors by a sequence of matrices that perform the needed transformation. The transformations will first shift the points in a way so that the rotation point is about the origin. We will then rotate about the origin by the desired about. And then we move the rotated points up by one unit to account for the initial translation.
    🔗

    Step 1: Shift Points Down by 1 Unit.

    In homogeneous coordinates our three points can be represented by the vectors below.
    \begin{equation*} \vec a = \begin{pmatrix} 1\\1\\1 \end{pmatrix}, \quad \vec b = \begin{pmatrix} 2\\3\\1 \end{pmatrix}, \quad \vec c = \begin{pmatrix} 3\\1\\1 \end{pmatrix} \end{equation*}
    Multiplying each vector by the matrix
    \begin{equation*} A_1 = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    shifts the points down by one unit.
    \begin{align*} \vec a = \begin{pmatrix} 1\\1\\1 \end{pmatrix} \to \amp \ A_1 \vec a = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1\\1\\1 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix}\\ \vec b = \begin{pmatrix} 2\\3\\1 \end{pmatrix} \to \amp \ A_1 \vec b = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 2\\3\\1 \end{pmatrix} = \begin{pmatrix} 2 \\ 2 \\ 1 \end{pmatrix}\\ \vec c = \begin{pmatrix} 3\\1\\1 \end{pmatrix} \to \amp \ A_1 \vec c = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 3 \\1 \\1 \end{pmatrix} = \begin{pmatrix} 3 \\ 0 \\ 1 \end{pmatrix} \end{align*}
    Note the difference between the input and output vectors. The second entry of the output vectors is one less than their corresponding entries in the input vectors. Our translated triangle and rotation point is shown below.
    🔗
    With this transform, the rotation point also moves down one unit, from \((0,1)\) to the origin \((0,0)\text{.}\)
    🔗
    🔗

    Step 2: Rotate About \(\mathbf{(0,0)}\).

    Rotating the translated points by \(\pi/2\) radians about the origin can be calculated by multiplying the three vectors by the matrix
    \begin{equation*} A_2 = \begin{pmatrix} 0 \amp -1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    This gives us three new points.
    \begin{align*} \vec a = \begin{pmatrix} 1\\1\\1 \end{pmatrix} \to \amp \ A_2A_1 \vec a = \begin{pmatrix} 0 \amp -1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}\\ \vec b = \begin{pmatrix} 2\\3\\1 \end{pmatrix} \to \amp \ A_2A_1 \vec b = \begin{pmatrix} 0 \amp -1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 2 \\ 2 \\ 1 \end{pmatrix} = \begin{pmatrix} -2 \\ 2 \\ 1 \end{pmatrix}\\ \vec c = \begin{pmatrix} 3\\1\\1 \end{pmatrix} \to \amp \ A_2A_1 \vec c = \begin{pmatrix} 0 \amp -1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 3 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 3 \\ 1 \end{pmatrix} \end{align*}
    🔗
    Finally, to undo the initial translation that placed the rotation point at the origin, we need to translate our points up by one unit.
    🔗
    🔗

    Step 3: Translate Points Up One Unit.

    Translating the data up by one unit can be accomplished by multiplying the three vectors by the matrix
    \begin{equation*} A_3 = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    This gives us three new points.
    \begin{align*} \vec a = \begin{pmatrix} 1\\1\\1 \end{pmatrix} \to \amp \ A_3A_2A_1 \vec a = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 2 \\ 1 \end{pmatrix}\\ \vec b = \begin{pmatrix} 2\\3\\1 \end{pmatrix} \to \amp \ A_3A_2A_1 \vec b = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} -2 \\ 2 \\ 1 \end{pmatrix} = \begin{pmatrix} -2 \\ 3 \\ 1 \end{pmatrix}\\ \vec c = \begin{pmatrix} 3\\1\\1 \end{pmatrix} \to \amp \ A_3A_2A_1 \vec c = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \\ 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 4 \\ 1 \end{pmatrix} \end{align*}
    🔗
    Our rotated and translated triangle is shown below.
    🔗
    Therefore the standard matrix that performs a rotation by \(\pi/2\) degrees about \((0,1)\) is the matrix
    \begin{align*} A = A_3A_2A_1 \amp = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \amp -1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \amp = \begin{pmatrix} 0 \amp -1 \amp 1 \\ 1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    Our result can be verified by calculating \(A\vec a\text{,}\) \(A\vec b\text{,}\) or \(A \vec c\text{.}\)
    🔗
    🔗
    🔗

    Subsection Example 3: A Reflection Through The Line \(x_2 = x_1 + 3\)

    In this example we construct the \(3\times3\) standard matrix, \(A\text{,}\) that uses homogeneous coordinates to reflect points in \(\R^2\) across the line \(x_2 = x_1 + 3\text{.}\) We will confirm that our results are correct by calculating \(T(\vec x) = A\vec x\) for any point \(\vec x\) that uses homogeneous coordinates.
    🔗
    The standard matrix \(A\) will be the product of three matrices that translate and reflect points using homogeneous coordinates. The first matrix will translate points in some way so that the line about which we are reflecting will pass through the origin. We can use
    \begin{equation*} A_1 = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    This matrix will shift points down three units so that the line \(x_2 = x_1 + 3\) will pass through the origin. Note that at this point we could have also used a matrix that, for example, shifts to the right by three units. The second matrix will reflect points through the shifted line, which is \(x_2 = x_1\text{.}\) Recall that the matrix
    \begin{equation*} \begin{pmatrix} 0 \amp 1 \\ 1 \amp 0 \end{pmatrix} \end{equation*}
    will reflect vectors in \(\R^2\) through the line \(x_2 = x_1\text{.}\) This is because any point with coordinates \((x_1,x_2)\) can be represented with the vector
    \begin{equation*} \vec x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} \end{equation*}
    and
    \begin{equation*} \begin{pmatrix} 0 \amp 1 \\ 1 \amp 0 \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} x_2 \\ x_1 \end{pmatrix} \end{equation*}
    🔗
    The point \((x_1,x_2)\) is mapped to \((x_2,x_1)\text{,}\) which is a reflection through the line \(x_2 = x_1\) in \(\R^2\text{.}\) The standard matrix for this transformation in homogeneous coordinates is
    \begin{equation*} A_2 = \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    Our final transformation shifts points back up by three units to undo the initial translation.
    \begin{equation*} A_3 = \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    The standard matrix for the transformation that reflects points in \(\R^2\) across the line \(x_2 = x_1 + 3\) is
    \begin{align*} A = A_3A_2A_1 \amp = \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \amp = \begin{pmatrix} 0 \amp 1 \amp -3 \\ 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    We can check whether our work is correct by transforming any point \((x_1,x_2)\) with the above standard matrix. For example, the point \((1,1)\) is transformed by calculating
    \begin{equation*} T(\vec x) = A\vec x = \begin{pmatrix} 0 \amp 1 \amp -3 \\ 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1\\1\\1 \end{pmatrix} = \begin{pmatrix} -2 \\ 4 \\ 1 \end{pmatrix} \end{equation*}
    The reflected point is \((-2,4)\text{.}\) The line of reflection, initial point, and the reflected point are shown below.
    🔗
    🔗

    Subsection The Data Matrix

    The examples in this section have only involved a small number points that need to be transformed. For problems involving many points, it may be more convenient to represent the points in what we refer to as a data matrix. For example, the shape in the figure below is determined by five points, or vertices, \(d_1, d_2, \ldots , d_5\text{.}\) Their respective homogeneous coordinates can be stored in the columns of a matrix, \(D\text{.}\)
    \begin{equation*} D = \begin{pmatrix} \vec d_1 \amp \vec d_2 \amp \vec d_3 \amp \vec d_4 \amp \vec d_5 \end{pmatrix} = \begin{pmatrix} 2 \amp 2 \amp 3 \amp 4 \amp 4 \\ 1 \amp 2 \amp 3 \amp 2 \amp 1 \\ 1 \amp 1 \amp 1 \amp 1 \amp 1 \end{pmatrix} \end{equation*}
    For our purposes, the order in which the points are placed into \(D\) is arbitrary.
    🔗
    In the previous examples we applied a transform with a matrix-vector multiplication. With a data matrix we can use a similar approach. Recall that the product of two matrices \(A\) and \(D\text{,}\) is defined as
    \begin{equation*} AD = A\begin{pmatrix} \vec d_1 \amp \vec d_2 \amp \cdots \amp \vec d_p \end{pmatrix} = \begin{pmatrix} A\vec d_1 \amp A\vec d_2 \amp \cdots \amp A\vec d_p \end{pmatrix} \end{equation*}
    where \(\vec d_1, \vec d_2, \cdots , \vec d_p\) are the columns of \(D\text{.}\) In other words, can perform the transformation on our data by computing \(AD\text{,}\) which transforms each column independently of the others.
    🔗
    For example, applying the transform in the previous example will reflect our shape through the line \(x_2 = x_1 + 3\text{.}\) The transformation is found by computing
    \begin{align*} AD \amp = \begin{pmatrix} 0 \amp 1 \amp -3 \\ 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 2 \amp 2 \amp 3 \amp 4 \amp 4 \\ 1 \amp 2 \amp 3 \amp 2 \amp 1 \\ 1 \amp 1 \amp 1 \amp 1 \amp 1 \end{pmatrix}\\ \amp = \begin{pmatrix} -2 \amp -1 \amp 0 \amp -1 \amp -2 \\ 5 \amp 5 \amp 6 \amp 7 \amp 7 \\ 1 \amp 1 \amp 1 \amp 1 \amp 1 \end{pmatrix} \end{align*}
    Extracting the first two entries of each column of the result gives us the transformed points (green), as shown in the figure below.
