    Worksheet 1.2 The LU Factorization
    

    To solve a linear system of the form \(A\vec{x} = \vec{b}\) we could use row reduction or, in theory, calculate \(A^{-1}\) and use it to determine \(\vec{x}\) with the equation
    🔗
    \begin{equation*} \vec{x} = A^{-1}\vec{b} \end{equation*}
    But computing \(A^{-1}\) requires the computation of the inverse of an \(n \times n\) matrix, which is especially difficult for large \(n\text{.}\) It is more practical to solve \(A\vec{x} = \vec{b}\) with row reductions (i.e. Gaussian Elimination). But it turns out that there are more efficient methods, especially when \(n\) is large.
    🔗
    One method for solving linear systems relies on what is referred to as a matrix factorization. A matrix factorization, or matrix decomposition is a factorization of a matrix into a product of matrices. Factorizations can be useful for solving \(A\vec{x} = \vec{b}\text{,}\) or for understanding the properties of a matrix.
    🔗
    In this section, we factor a matrix into lower and into upper triangular matrices to construct what is known as the LU factorization that is used to solve linear systems in a systematic and efficient method. Before we introduce the LU factorization, we will first need to introduce lower and upper triangular matrices.
    🔗
    \({\large \textbf{1.2.1 Triangular Matrices}}\)
    Before we introduce the LU factorization, we need to first define upper and lower triangular matrices.
    🔗
    \({\large \textbf{Upper and Lower Triangular Matrices}}\)
    Suppose that the entries of \(m \times n\) matrix \(A\) are \(a_{i,j}\text{.}\) Then \(A\) is upper triangular if \(a_{i,j} = 0\) for \(i > j\text{.}\) Matrix \(A\) is lower triangular if \(a_{i,j} = 0\) for \(i < j\text{.}\)
    🔗
    As an example, all of the matrices below are in upper triangular form.
    🔗
    \begin{equation*} \begin{pmatrix} 1 \amp 5 \amp 0 \\ 0 \amp 2 \amp 4 \end{pmatrix}, \quad \begin{pmatrix} 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 2 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{pmatrix}, \quad \begin{pmatrix} 2 \amp 1 \\ 0 \amp 1 \\ 0 \amp 0 \\ 0 \amp 0 \end{pmatrix}, \quad \begin{pmatrix} 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    Notice how all of the entries below the main diagonal are zero, and the entries on and above the main diagonal can be anything. Likewise, examples of lower triangular matrices are below.
    🔗
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 3 \amp 2 \amp 0 \end{pmatrix}, \quad \begin{pmatrix} 3 \amp 0 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \amp 1 \end{pmatrix}, \quad \begin{pmatrix} 1 \amp 0 \\ 1 \amp 4 \\ 0 \amp 1 \\ 2 \amp 0 \end{pmatrix}, \quad \begin{pmatrix} 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    Again, note that our definition for an upper triangular matrix does not specify what the entries on or above the main diagonal need to be. Some or all of the entries above the main diagonal can, for example, be zero. Likewise the entries on and below the main diagonal of a lower triangular matrix do not have to have specific values.
    🔗
    \({\large \textbf{1.2.2 The LU Factorization}}\)
    After stating a theorem that gives the LU decomposition, we will give an algorithm for constructing the LU factorization. We will then see how we can use the factorization to solve a linear system.
    🔗
    \({\large \textbf{Theorem: The LU Factorization}}\)
    If \(A\) is an \(m \times n\) matrix that can be row reduced to echelon form without row exchanges, then \(A = LU\text{,}\) where \(L\) is a lower triangular \(m \times m\) matrix with 1’s on the diagonal, and \(U\) is an echelon form of \(A\text{.}\)
    🔗
    \({\large \textbf{Proof}}\)
    To prove the theorem above we will first show that we can write \(A = LU\) where \(L\) is an invertible matrix, and \(U\) is an echelon form of \(A\text{.}\)
    🔗
    Suppose that \(m \times n\) matrix \(A\) can be reduced to echelon form \(U\) with \(p\) elementary row operations that only add a multiple of a row to another row that is below it. Then each row operation can be performed by multiplying \(A\) with \(p\) elementary matrices.
    🔗
    \begin{equation*} E_pE_{p-1} \cdots E_3E_2E_1A = U \quad \quad \quad \text{(1.2)} \end{equation*}
    If we let \(L^{-1} = E_pE_{p-1} \cdots E_3E_2E_1\text{,}\) then
    🔗
    \begin{equation*} L^{-1}A = U \quad \quad \quad \text{(1.3)} \end{equation*}
    Note that \(L^{-1} = E_pE_{p-1} \cdots E_3E_2E_1\) is invertible because elementary matrices are invertible. Therefore \(L^{-1}\) can be reduced to the identity with a sequence of row operations. Moreover, if we multiply Equation (1.3) by \(L\) we obtain:
    🔗
    \begin{equation*} LL^{-1}A = LU \quad \Rightarrow \quad A = LU \end{equation*}
    Therefore \(A\) has the decomposition \(A = LU\) where \(U\) is an echelon form of \(A\) and \(L\) is an invertible \(m \times m\) matrix. To show that \(L\) is lower triangular, recall from Equations (1.2) and (1.3) that
    🔗
    \begin{equation*} L^{-1} = E_pE_{p-1} \cdots E_3E_2E_1 \end{equation*}
    Each elementary matrix \(E_i\) is lower triangular because to reduce \(A\) to \(U\) we only used one type of row operation: adding a multiple of a row to a row below it, so each \(E_i\) is a lower triangular matrix. It can also be shown that the product of two lower-triangular matrices is a lower triangular matrix, and the inverse of a lower triangular matrix is lower triangular. This implies that both \(L^{-1}\) and \(L\) will be lower-triangular.
    🔗
    \({\large \textbf{1.2.3 Constructing the LU Factorization}}\)
    To construct the LU factorization of a matrix we must first apply a sequence of row operations to \(A\) in order to reduce \(A\) to \(U\text{.}\) Equation (1.3) gives us that
    🔗
    \begin{equation*} E_pE_{p-1} \cdots E_3E_2E_1A = L^{-1}A = U, \quad \text{where } L^{-1} = E_pE_{p-1} \cdots E_3E_2E_1 \end{equation*}
    But if \(L^{-1}L = I\text{,}\) then the sequence of row operations that reduce \(A\) to \(U\) will reduce \(L\) to \(I\text{.}\) This gives us an algorithm for constructing the LU factorization.
    🔗
    \({\large \textbf{Algorithm: Constructing the LU Factorization of a Matrix}}\)
    Suppose \(A\) is an \(m \times n\) matrix that can be row reduced to echelon form without row exchanges. To construct the LU factorization:
    🔗
    1. reduce \(A\) to an echelon form \(U\) by a sequence of row replacement operations, if possible
    🔗
    2. place entries in \(L\) such that the sequence of row operations that reduces \(A\) to \(U\) will reduce \(L\) to \(I\)
    🔗
    Note that the above procedure will work for any \(m \times n\) matrix that can be reduced to echelon form without row exchanges. Meaning that we do not need \(A\) to be square or invertible to construct its LU factorization.
    🔗
    \({\large \textbf{1.2.4 Example 1: LU of a }3 \times 2\text{ Matrix}}\)
    In this example we construct LU factorizations of the following matrix.
    🔗
    \begin{equation*} A = \begin{pmatrix} 1 \amp 3 \\ 2 \amp 10 \\ 0 \amp 12 \end{pmatrix} \end{equation*}
    Because \(A\) is a \(3 \times 2\) matrix, the LU factorization has the form
    🔗
    \begin{equation*} A = LU = \begin{pmatrix} 1 \amp 0 \amp 0 \\ * \amp 1 \amp 0 \\ * \amp * \amp 1 \end{pmatrix} \begin{pmatrix} * \amp * \\ 0 \amp * \\ 0 \amp 0 \end{pmatrix} \quad \quad \quad \text{(1.4)} \end{equation*}
    Each \(*\) represents an entry that we need to compute the value of. To reduce \(A\) to \(U\) we apply a sequence of row replacement operations as shown below.
    🔗
    \begin{equation*} A = \begin{pmatrix} 1 \amp 3 \\ 2 \amp 10 \\ 0 \amp 12 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 3 \\ 0 \amp 4 \\ 0 \amp 12 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 3 \\ 0 \amp 4 \\ 0 \amp 0 \end{pmatrix} = U \end{equation*}
    Matrix \(U\) is the echelon form of \(A\) that we need for the LU factorization. We next construct \(L\) so that the row operations that reduced \(A\) to \(U\) will reduce \(L\) to \(I\text{.}\) Our row operations were:
    🔗
    \begin{equation*} R_2 - 2R_1 \to R_2 \quad \text{and} \quad R_3 - 3R_2 \to R_3 \end{equation*}
    With these two row operations, we see that \(L\) must be the matrix:
    🔗
    \begin{equation*} L = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 2 \amp 1 \amp 0 \\ 0 \amp 3 \amp 1 \end{pmatrix} \end{equation*}
    Note that the row operations \(R_2 - 2R_1 \to R_2\) and \(R_3 - 3R_2 \to R_3\) applied to \(L\) will give us the identity. The LU factorization of \(A\) is
    🔗
    \begin{equation*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 2 \amp 1 \amp 0 \\ 0 \amp 3 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \amp 3 \\ 0 \amp 4 \\ 0 \amp 0 \end{pmatrix} \end{equation*}
    \({\large \textbf{1.2.5 Solving Linear Systems with the LU Factorization}}\)
    Our motivation for introducing the LU factorization was to introduce an efficient method for solving linear systems. Given rectangular matrix \(A\) and vector \(\vec{b}\text{,}\) we wish to use the LU factorization of \(A\) to solve \(A\vec{x} = \vec{b}\) for \(\vec{x}\text{.}\) A procedure for doing so is below.
    🔗
    \({\large \textbf{Algorithm}}\)
    To solve \(A\vec{x} = \vec{b}\) for \(\vec{x}\text{:}\)
    🔗
    1. Construct the LU decomposition of \(A\) to obtain \(L\) and \(U\text{.}\)
    🔗
    2. Set \(U\vec{x} = \vec{y}\text{.}\) Forward solve for \(\vec{y}\) in \(L\vec{y} = \vec{b}\text{.}\)
    🔗
    3. Backwards solve for \(\vec{x}\) in \(U\vec{x} = \vec{y}\text{.}\)
    🔗
    \({\large \textbf{1.2.6 Example 2: Solving a Linear System With LU}}\)
    In this example we will solve the linear system \(A\vec{x} = \vec{b}\) given the LU decomposition of \(A\text{.}\)
    🔗
    \begin{equation*} A = LU = \begin{pmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 1 \amp 0 \\ 0 \amp 0 \amp 3 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \amp 4 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 2 \\ 0 \amp 0 \amp 0 \end{pmatrix}, \quad \vec{b} = \begin{pmatrix} 2 \\ 3 \\ 2 \\ 0 \end{pmatrix} \end{equation*}
    We first set \(U\vec{x} = \vec{y}\) and solve \(L\vec{y} = \vec{b}\text{.}\) Reducing the augmented matrix \((L \mid \vec{b})\) gives us:
    🔗
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0 \amp 0 \amp 2 \\ 1 \amp 1 \amp 0 \amp 0 \amp 3 \\ 0 \amp 2 \amp 1 \amp 0 \amp 2 \\ 0 \amp 0 \amp 3 \amp 1 \amp 0 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 0 \amp 0 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 2 \amp 1 \amp 0 \amp 2 \\ 0 \amp 0 \amp 3 \amp 1 \amp 0 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 0 \amp 0 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 3 \amp 1 \amp 0 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 0 \amp 0 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 0 \end{pmatrix} \end{equation*}
    Therefore, \(\vec{y}\) is the vector
    🔗
    \begin{equation*} \vec{y} = \begin{pmatrix} 2 \\ 1 \\ 0 \\ 0 \end{pmatrix}. \end{equation*}
    We now solve \(U\vec{x} = \vec{y}\text{.}\)
    🔗
    \begin{equation*} \begin{pmatrix} 1 \amp 4 \amp 1 \amp 2 \\ 0 \amp 1 \amp 1 \amp 1 \\ 0 \amp 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 4 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 0 \amp 0 \amp -2 \\ 0 \amp 1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    The solution to the linear system, \(\vec{x}\text{,}\) is the vector
    🔗
    \begin{equation*} \vec{x} = \begin{pmatrix} -2 \\ 1 \\ 0 \end{pmatrix} \end{equation*}
    \({\large \textbf{1.2.7 Final Notes on The LU Factorization}}\)
    In our treatment of the LU factorization we constructed the LU decomposition using the following process.
    🔗
    1. reduce \(A\) to an echelon form \(U\) by a sequence of row replacement operations, if possible
    🔗
    2. place entries in \(L\) such that the same sequence of row operations reduces \(L\) to \(I\)
    🔗
    There is much more to the LU factorization than what was presented in this section. There are for example other methods for constructing \(A = LU\) that you may encounter in future courses or projects you are working on. In our approach, the only row operation we use to construct \(L\) and \(U\) is to replace a row with a multiple of a row above it. Multiplying a row by a non-zero scalar is not needed, but more importantly, we cannot swap rows. More advanced linear algebra and numerical analysis courses would address this significant limitation.
    🔗
