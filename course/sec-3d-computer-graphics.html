    Section 3D Computer Graphics

    Results from the previous section on 2D graphics have a natural extension to three dimensions. In this section we extend the data matrix and homogeneous coordinates to three dimensions. This will allow us to model translations and composite transforms involving many points with matrix multiplication.
    🔗

    Subsection Rotations in 3D

    Rotations about the origin are linear transforms. Because they are linear they can be expressed in the form \(T(\vec x) = A\vec x\) where \(A\) is a \(3\times 3\) matrix, and we can obtain the columns of matrix \(A\) by transforming the standard vectors
    \begin{equation*} \vec e_1 = \begin{pmatrix} 1\\0\\0 \end{pmatrix}, \quad \vec e_2 = \begin{pmatrix} 0\\1\\0 \end{pmatrix}, \quad \vec e_3 = \begin{pmatrix} 0\\0\\1 \end{pmatrix} \end{equation*}
    We will use the convention that a positive rotation is in the counterclockwise direction when looking toward the origin from the positive half of the axis of rotation. For example, rotating \(\vec e_1\) about the \(x_3\)-axis by \(\theta\) radians results in the vector
    \begin{equation*} T(\vec e_1) = \begin{pmatrix} \cos\theta\\\sin\theta\\0 \end{pmatrix} \end{equation*}
    Transforming the first standard vector \(\vec e_1\) yields the first column of \(A\text{.}\) Likewise the remaining columns can be found by transforming the other standard vectors.
    \begin{equation*} T(\vec e_2) = \begin{pmatrix} - \sin\theta\\\cos\theta\\0 \end{pmatrix}, \quad T(\vec e_3) = \begin{pmatrix} 0\\0\\1 \end{pmatrix} \end{equation*}
    The third standard vector does not change under this transformation because it is parallel to the rotation axis. The standard matrix for a rotation about the \(x_3\)-axis is
    \begin{equation*} A = \begin{pmatrix} T(\vec e_1) \amp T(\vec e_2) \amp T(\vec e_3) \end{pmatrix} = \begin{pmatrix} \cos \theta \amp -\sin\theta \amp 0 \\ \sin\theta \amp \cos\theta \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    A similar analysis gives us the standard matrices for rotations about the \(x_1\) and the \(x_2\) axes. Results are summarized in Table 4. The standard matrices in the table can be multiplied together to model transforms that perform multiple transformations. The next example demonstrates this application.
    🔗
    🔗

    Subsection Example 1: 3D Rotations

    Suppose that the transform \(\vec{x}\to A\vec x\) first rotates points in \(\R^3\) about the \(x_2\)-axis by \(\pi/2\) radians and then rotates points about the \(x_1\)-axis by \(\pi\) radians. We can determine the standard matrix, \(A\text{,}\) for this transform in a few different ways. One approach is to use the standard matrices in Table 4. The standard matrix, \(A\text{,}\) is the product of two rotation matrices.
    \begin{align*} A \amp = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp \cos \pi \amp -\sin\pi \\ 0 \amp \sin\pi \amp \cos\pi \end{pmatrix} \begin{pmatrix} \cos (\pi/2) \amp 0 \amp -\sin(\pi/2) \\ 0 \amp 1 \amp 0 \\ \sin(\pi/2) \amp 0 \amp \cos(\pi/2) \end{pmatrix}\\ \amp = \begin{pmatrix} 0 \amp 0 \amp -1 \\ 0 \amp -1 \amp 0 \\ -1 \amp 0 \amp 0 \end{pmatrix} \end{align*}
    Note that the rotation about the \(x_2\)-axis is applied before the rotation about the \(x_1\)-axis, which determines the multiplication order. The standard matrix for the first transformation is placed in the rightmost position.
    🔗
    We could also obtain the same result by transforming the standard vectors, because \(A = \begin{pmatrix} T(\vec e_1) \amp T(\vec e_2) \amp T(\vec e_3) \end{pmatrix} \text{.}\) The first standard vector gives us the first column of \(A\text{.}\)
    \begin{equation*} \vec e_1 = \begin{pmatrix} 1\\0\\0 \end{pmatrix} \to \begin{pmatrix} 0\\0\\1 \end{pmatrix} \to \begin{pmatrix} 0\\0\\-1 \end{pmatrix} \end{equation*}
    This result agrees with our result obtained above by multiplying rotation matrices together. Note also that our convention is that a positive rotation is in the counterclockwise direction when looking toward the origin from the positive half of the axis of rotation.
    🔗
    🔗

    Subsection The Data Matrix for 3D Transforms

    Similar to the 2D case, for problems involving many points it is convenient to represent the points a data matrix. Analogous to our approach in 2D, points in \(\R^3\) can be represented in a matrix whose columns are vectors that correspond to the points we wish to transform. We may transform this matrix with a matrix-vector multiplication. Recall that the product of two matrices \(A\) and \(D\text{,}\) is defined as
    \begin{equation*} AD = A\begin{pmatrix} \vec d_1 \amp \vec d_2 \amp \cdots \amp \vec d_p \end{pmatrix} = \begin{pmatrix} A\vec d_1 \amp A\vec d_2 \amp \cdots \amp A\vec d_p \end{pmatrix} \end{equation*}
    where \(\vec d_1, \vec d_2, \cdots , \vec d_p\) are the columns of \(D\text{.}\) In other words, can perform the transformation on our data by computing \(AD\text{,}\) which transforms each column independently of the others. The following example demonstrates this approach.
    🔗
    🔗

    Subsection Example 2: A Projection in 3D with the Data Matrix

    Data in Table (5) define a cube in \(\R^3\) with side length 1. Suppose the linear transform \(T(\vec x)\) projects points in \(\R^3\) onto the \(x_1x_2\)-plane. In this example we will construct the matrix, \(A\text{,}\) that is the standard matrix of the transformation \(T(\vec x) = A \vec x\text{.}\)
    🔗
    The data in Table (5) (blue) and its projection (green) are shown Figure (5).
    🔗
    Because the given transform that we are dealing with in this example is linear, we can express the transform in the form of a matrix-vector product
    \begin{equation*} T(\vec x) = A\vec x \end{equation*}
    where \(A\) is a \(3\times3\) matrix. Moreover, because we are working with a linear transform, each column of \(A\) is equal to the product
    \begin{equation*} A\vec e_i, \quad i = 1,2,3 \end{equation*}
    and \(\vec e_i\) is a standard vector. For example, the first column of \(A\) can be found using \(\vec e_1\text{,}\) which is the vector
    \begin{equation*} \vec e_1 = \begin{pmatrix} 1\\0\\0 \end{pmatrix} \end{equation*}
    Projecting \(\vec e_1\) onto the \(x_1x_2\)-plane does not change the vector, because the vector is already in that plane.
    \begin{equation*} \vec e_1 \to A\vec e_1 = \vec e_1 = \text{first column of } A \end{equation*}
    The first column of \(A\) is \(\vec e_1\text{.}\) Likewise, the second column of \(A\) is \(\vec e_2\text{,}\) becuase \(\vec e_2\) is also already in the \(x_1x_2\)-plane.
    \begin{equation*} \vec e_2 = \begin{pmatrix} 0\\1\\0 \end{pmatrix} \to A\vec e_2 = \vec e_2 = \text{second column of } A \end{equation*}
    The last column of \(A\) is the projection of \(\vec e_3\) onto the plane, which is the zero vector.
    \begin{equation*} \vec e_3 = \begin{pmatrix} 0\\0\\1 \end{pmatrix} \to A\vec e_3 = \begin{pmatrix} 0\\0\\0 \end{pmatrix} = \text{third column of } A \end{equation*}
    Combining our results for each column of \(A\) gives us the standard matrix.
    \begin{equation*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    Now that we have the standard matrix for this transform, we can use it to transform the data in Table 1. Representing each point as a vector in \(\R^3\) and placing the vectors in a data matrix, \(D\text{,}\) will allow us to compute the projection using a matrix multiplication. Our matrix \(D\) is
    \begin{equation*} D = \begin{pmatrix} 1 \amp 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2 \amp 2 \\ 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2 \amp 2 \amp 1 \\ 1 \amp 1 \amp 1 \amp 1 \amp 2 \amp 2 \amp 2 \amp 2 \end{pmatrix} \end{equation*}
    The transformed points can be computed as follows.
    \begin{align*} AD \amp = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \begin{pmatrix} 1 \amp 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2 \amp 2 \\ 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2 \amp 2 \amp 1 \\ 1 \amp 1 \amp 1 \amp 1 \amp 2 \amp 2 \amp 2 \amp 2 \end{pmatrix}\\ \amp = \begin{pmatrix} 1 \amp 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2 \amp 2 \\ 1 \amp 2 \amp 2 \amp 1 \amp 1 \amp 2 \amp 2 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \end{align*}
    Extracting the columns of the product gives us the projected points.

    🔗

    Subsection 3D Homogeneous Coordinates

    Homogeneous coordinates in 3D are analogous to the homogeneous 2D coordinates we introduced in the previous section.
    🔗

    Homogeneous Coordinates in \(\R^3\).

    \((X,Y,Z,1)\) are homogeneous coordinates for \((x,y,z)\) in \(\R^3\)
    🔗
    🔗
    A translation of the form \((x,y,z) \to (x+h,y+k,z+l)\) can be represented as a matrix multiplication with homogeneous coordinates:
    \begin{equation*} \begin{pmatrix} 1 \amp 0 \amp 0 \amp h \\ 0 \amp 1 \amp 0 \amp k \\ 0 \amp 0 \amp 1 \amp l \\ 0 \amp 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} x\\y\\z\\1 \end{pmatrix} = \begin{pmatrix} x+h\\y+k\\z+l\\1 \end{pmatrix} \end{equation*}
    🔗

    Example 3: A Translation in 3D.

    The data in Table (5) can be translated using a homogeneous coordinate system. The data matrix \(D_n\) in homogeneous coordinates would be
