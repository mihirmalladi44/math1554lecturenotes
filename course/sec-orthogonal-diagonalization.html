    Section 2.1 Orthogonal Diagonalization

    Many algorithms rely on a type of matrix that is equal to its transpose. If matrix \(A\) satisfies \(A=A^T\text{,}\) then \(A\) is symmetric. A common example of a symmetric matrix is the product \(A^TA\text{,}\) where \(A\) is any \(m\times n\) matrix. We use \(A^TA\) when, for example, constructing the normal equations in least-squares problems. One way to see that \(A^TA\) is symmetric for any matrix \(A\) is to take the transpose of \(A^TA\text{.}\)
    \begin{equation*} (A^TA)^T = A^TA^{TT} = A^TA \end{equation*}
    \(A^TA\) is equal to its transpose so it must be symmetric. But another way to see that \(A^TA\) is symmetric is that for any rectangular matrix \(A\) with columns \(a_1,\dotsc,a_n\text{,}\) is to express the matrix product using the row-column rule for matrix multiplication.
    🔗
    \begin{equation*} A^T A = \begin{pmatrix} \text{---} \amp a_1^{T} \amp \text{---} \\ \text{---} \amp a_2^{T} \amp \text{---} \\ \vdots \amp \vdots \amp \vdots \\ \text{---} \amp a_n^{T} \amp \text{---} \end{pmatrix} \begin{pmatrix} \vert \amp \vert \amp \cdots \amp \vert \\ a_1 \amp a_2 \amp \cdots \amp a_n \\ \vert \amp \vert \amp \cdots \amp \vert \end{pmatrix} = \underbrace{ \begin{pmatrix} a_1^{T}a_1 \amp a_1^{T}a_2 \amp \cdots \amp a_1^{T}a_n \\ a_2^{T}a_1 \amp a_2^{T}a_2 \amp \cdots \amp a_2^{T}a_n \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ a_n^{T}a_1 \amp a_n^{T}a_2 \amp \cdots \amp a_n^{T}a_n \end{pmatrix} }_{\text{entries are dot products of columns of } A} \end{equation*}
    🔗
    Note that \(a_i^Ta_j\) is the dot product between \(a_i\) and \(a_j\text{.}\) And because dot products commute, in other words
    \begin{equation*} a_i^T a_j = a_i \cdot a_j = a_j \cdot a_i = a_j^Ta_i \end{equation*}
    \(A^TA\) is symmetric.
    🔗
    One of the reasons that symmetric matrices are found in many algorithms is that they posses several properties that we can use to make useful or efficient calculations. In this section we investigate some of these properties that symmetric matrices have. In later sections of this chapter we will use these properties to develop and understand algorithms and their results.
    🔗

    Subsection Properties of Symmetric Matrices

    In this section we give three theorems that characterize symmetric matrices.
    🔗

    Subsubsection 1) Symmetric Matrices Have Orthogonal Eigenspaces

    The eigenspaces of symmetric matrices have a useful property that we can use when, for example, diagoanlizing a matrix.
    🔗

    Theorem 7. Theorem.

    If \(A\) is a symmetric matrix, with eigenvectors \(\vec v_1\) and \(\vec v_2\) corresponding to two distinct eigenvalues, then \(\vec v_1\) and \(\vec v_2\) are orthogonal.
    🔗
    🔗
    More generally this theorem implies that eigenspaces associated to distinct eigenvalues are orthogonal subspaces.
    🔗

    Proof.
    Our approach will be to show that if \(A\) is symmetric then any two of its eigenvectors \(\vec v_1\) and \(\vec v_2\) must be orthogonal when their corresponding eigenvalues \(\lambda_1\) and \(\lambda_2\) are not equal to each other.
    🔗
    \begin{align} \lambda_1 \vec v_1 \cdot \vec v_2 \amp= A\vec v_1 \cdot \vec v_2 \amp\amp \text{using } A\vec v_i = \lambda_i \vec v_i\tag{1}\\ \amp= (A\vec v_1)^T\vec v_2 \amp\amp \text{using the definition of the dot product}\tag{2}\\ \amp= \vec v_1\,^TA^T\vec v_2 \amp\amp \text{property of transpose of product}\tag{3}\\ \amp= \vec v_1\,^TA\vec v_2 \amp\amp \text{given that } A = A^T\tag{4}\\ \amp= \vec v_1 \cdot A\vec v_2 \amp\amp \text{again using the definition of the dot product}\tag{5}\\ \amp= \vec v_1 \cdot \lambda_2 \vec v_2 \amp\amp \text{using } A\vec v_i = \lambda_i \vec v_i\tag{6}\\ \amp= \lambda_2 \vec v_1 \cdot \vec v_2\tag{7} \end{align}
    Rearranging the equation yields
    🔗
    \begin{align} 0 \amp= \lambda_2 \vec v_1 \cdot \vec v_2 - \lambda_1 \vec v_1 \cdot \vec v_2\tag{8}\\ \amp= (\lambda_2 - \lambda_1) \vec v_1 \cdot \vec v_2\tag{9} \end{align}
    But \(\lambda_1 \ne \lambda_2\) so \(\vec v_1 \cdot \vec v_2 = 0\text{.}\) In other words, eigenvectors corresponding to distinct eigenvalues must be orthogonal.
    🔗
    🔗
    This theorem can be sometimes be used to quickly identify the eigenvectors of a matrix. For example, if \(A\) is a \(2\times2\) matrix and we know that \(\vec v_1\) is an eigenvector of \(A\text{,}\) then we can find any non-zero vector orthogonal to \(\vec v_1\) to identify the eigenvector for the other eigenspace.
    🔗
    🔗

    Subsubsection 2) The Eigenvalues of a Symmetric Matrix are Real

    Theorem 8. Theorem.

    If \(A\) is a real symmetric matrix then all eigenvalues of \(A\) are real.
    🔗
    🔗
    A proof of this result is in Appendix 1.2.
    🔗
    🔗

    Subsubsection 3) The Spectral Theorem

    It turns out that every real symmetric matrix can always be diagonalized using an orthogonal matrix, which is a result of the spectral theorem.
    🔗

    Theorem 9. The Spectral Theorem.

    An \(n \times n\) matrix \(A\) is symmetric if and only if the matrix can be orthogonally diagonalized.
    🔗
    🔗
    A proof of this theorem is beyond the scope of these notes, but there are several important consequences of this theorem. All symmetric matrices can not only be diagonalized, but they can be diagonalized with an orthogonal matrix. Moreover, the only matrices that can be diagonalized orthogonally are symmetric, and that if a matrix can be diagonalized with an orthogonal matrix, then it is symmetric.
    🔗
    🔗
    🔗

    Subsection Examples

    Example 10. Example 1: Orthogonal Diagonalization of a \(2\times 2\) Matrix.

    Suppose \(A\) is the symmetric matrix below.
    🔗
    \begin{equation*} A = \begin{pmatrix} 0 \amp -2 \\ -2 \amp 3 \end{pmatrix}, \quad \lambda_1 = 4, \quad \lambda_2=-1 \end{equation*}
    The eigenvalues of \(A\) are given. In this example we will diagonalize \(A\) using an orthogonal matrix, \(P\text{.}\) For eigenvalue \(\lambda_1 = 4\) we have
    \begin{equation*} A - \lambda_1 I = \begin{pmatrix} -4 \amp -2 \\ -2 \amp -1 \end{pmatrix} \end{equation*}
    A vector in the null space of \(A - \lambda_1 I\) is the eigenvector
    \begin{equation*} \vec v_1 = \begin{pmatrix} 1 \\ -2 \end{pmatrix} \end{equation*}
    🔗
    A vector orthogonal to \(\vec v_1\) is
    \begin{equation*} \vec v_2 = \begin{pmatrix} 2 \\ 1 \end{pmatrix} \end{equation*}
    which must be an eigenvector for \(\lambda_2\) because \(A\) is symmetric.
    🔗
    Dividing each of the eigenvectors by their respective length, and then collecting these unit vectors into a single matrix, \(P\text{,}\) we obtain an orthogonal matrix. In other words, \(P^{-1}P = PP^{-1} = I\text{.}\) This convenient property gives us a convenient way to compute \(P^{-1}\) should it be needed.
    🔗
    Placing the eigenvalues of \(A\) in the order that matches the order used to create \(P\text{,}\) we obtain the factorization
    \begin{equation*} A = PDP^T, \quad D = \begin{pmatrix} \lambda_1 \amp 0 \\ 0 \amp \lambda_2 \end{pmatrix}, \quad P = \frac{1}{\sqrt 5} \begin{pmatrix} 1 \amp 2 \\ -2 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    🔗

    Example 11. Example 2: Orthogonal Diagonalization of a \(3\times3\) Matrix.

    In this example we will diagonalize a matrix, \(A\text{,}\) using an orthogonal matrix, \(P\text{.}\)
    🔗
    \begin{equation*} A = \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix}, \quad \lambda = -1, 1 \end{equation*}
    The eigenvalues of \(A\) are given. For eigenvalue \(\lambda_1 = -1\) we have
    \begin{equation*} A - \lambda_1 I = \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 2 \amp 0 \\ 1 \amp 0 \amp 1 \end{pmatrix} \sim \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 2 \amp 0 \\ 1 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    A vector in the null space of \(A - \lambda_1 I\) is the eigenvector
    \begin{equation*} \vec v_1 = \begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix} \end{equation*}
    For eigenvalue \(\lambda_2 = 1\) we have
    \begin{equation*} A - \lambda_2 I = \begin{pmatrix} -1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \\ 1 \amp 0 \amp -1 \end{pmatrix} \sim \begin{pmatrix} -1 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{equation*}
    By inspection, two vectors in the null space of \(A - \lambda_2 I\) are
    \begin{equation*} \vec v_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \quad \vec v_3 = \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix} \end{equation*}
    🔗
    There are many other choices that we could make but the above two vectors will suffice. Note that \(\vec v_2\) and \(\vec v_3\) happen to be orthogonal to each other. If they happened to not be orthogonal, one could use the Gram-Schmidt procedure to make them so.
    🔗
    Dividing each of the three eigenvectors by their respective length, and then collecting these unit vectors into a single matrix, \(P\text{,}\) we obtain an orthogonal matrix. This will give us a matrix whose inverse is equal to its transpose. In other words, \(P\) is an orthogonal matrix, and \(P^{-1}P = PP^{-1} = I\text{.}\) This convenient property gives us a convenient way to compute \(P^{-1}\) should it be needed.
    🔗
    Placing the eigenvalues of \(A\) in the order that matches the order used to create \(P\text{,}\) we obtain the factorization
    \begin{equation*} A = PDP^T, \quad D = \begin{pmatrix} -1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}, \quad P = \frac{1}{\sqrt 2} \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp \sqrt2 \amp 0 \\ -1 \amp 0 \amp 1 \end{pmatrix} \end{equation*}
    🔗
    🔗
    🔗

    Subsection Summary

    In this section we explored how we might construct an orthogonal diagonalization of a symmetric matrix, \(A = PDP^T\text{.}\) Note that when a symmetric matrix has a repeated eigenvalue, Gram-Schmidt may be needed when eigenvalues are repeated to construct a full set of orthonormal eigenvectors that span \(\mathbb R^n\text{.}\) The theorems we introduced in this section gives us that
    🔗
    • all eigenvalues of \(A\) are real
      🔗
      🔗
    • eigenspaces of \(A\) are mutually orthogonal
      🔗
      🔗
    • \(A\) can be diagonalized as \(A = P D P^{T}\)
      🔗
      🔗
    🔗
