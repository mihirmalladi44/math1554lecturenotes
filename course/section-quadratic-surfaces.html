    Section 2.3 Quadratic Surfaces

    In a previous section of these notes we encountered situations where we want to minimize or maximize a quadratic function of the form
    🔗
    \begin{equation} Q = \vec x^{\,T} A \vec x\tag{17} \end{equation}
    where \(A \in \mathbb R^{2\times 2}\) is symmetric. Then the set of \(\vec x\) that satisfies Equation (17) We were also interested in additional constraints on what \(\vec x\) could be. These sorts of problems are encountered, for example, when constructing the singular value decomposition of a matrix, which we will get to soon. Either way, to help us understand thes2e constrained optimization problems it can be helpful to have a geometric interpretation of what Equation (17) represents. The interpretations and terminology we introduce in this section can help us describes the shape of \(Q\) and solve optimization problems related to it.
    🔗

    Subsection Example 1: A Quadratic Surface in \(\mathbb R^3\)

    For a fixed \(Q\text{,}\) Equation (17) will define a curve in \(\mathbb R^2\text{.}\) For example, if
    🔗
    \begin{equation*} A =\begin{pmatrix} 2 \amp 1 \\ 1 \amp 2 \end{pmatrix} \end{equation*}
    then the points that satisfy
    🔗
    \begin{equation*} Q = \vec x^{\,T} \begin{pmatrix} 2 \amp 1 \\ 1 \amp 2 \end{pmatrix} \vec x = 2x^2 +2y^2 +2xy \end{equation*}
    generates a curve in \(\mathbb R^2\text{.}\) The diagram below shows a set of curves for \(Q\) equal to 2 and to 8. As we vary the value of \(Q\text{,}\) the size of our curve will change. In general, when we increase the value of \(Q\text{,}\) the curve gets larger and points on the curve get further away from the origin. As we decrease \(Q\text{,}\) the opposite happens: the curve gets smaller and points on the curve get closer to the origin.
    🔗
    If we consider many values of \(Q\) we would generate many more curves in \(\mathbb R^2\text{.}\) The curves could also be displayed in \(\mathbb R^3\text{,}\) with one of the axes corresponding to \(Q\text{.}\) In fact, if we allow \(Q\) to vary continuously, \(Q = 2x^2 +2y^2 +2xy\) would give us a surface in \(\mathbb R^3\text{,}\) which is shown in Figure 17.
    🔗
    Those familiar with MATLAB may be surprised that the above surface can be generated using only a few lines of code. The script that was used to create Figure 17 is below. The code uses the fimplicit3 function.

The MATLAB fimplicit3 function plots the three dimensional implicit function defined by \(f(x,y,z) = 0\) over a default interval of \([-5, 5]\) for input values of \(x, y, z\text{.}\) By rearranging Equation (17) we can obtain \(Q-2y^2-2x^2-2xy = 0\) which is the form that MATLAB needs for fimplicit3.

    Subsection Classifying Quadratic Forms

    Quadratic functions of the form \(Q = \vec x^TA\vec x\) can be classified based on the values that \(Q\) can have.
    🔗

    Definition 20. Definition.

    A quadratic form \(Q\) is
    🔗
    • positive definite if \(Q > 0\) for all \(\vec x \ne \vec 0\text{.}\)
      🔗
      🔗
    • negative definite if \(Q<0\) for all \(\vec x \ne \vec 0\text{.}\)
      🔗
      🔗
    • positive semidefinite if \(Q\ge0\) for all \(\vec x\text{.}\)
      🔗
      🔗
    • negative semidefinite if \(Q\le0\) for all \(\vec x\text{.}\)
      🔗
      🔗
    • indefinite if \(Q\) takes on positive and negative values for \(\vec x \ne \vec 0\text{.}\)
      🔗
      🔗
    🔗
    That these categories are not mutually exclusive. A form can, for example, be both positive definite and positive semidefinite. The following theorem allows us to classify a form based on the eigenvalues of the matrix of the quadratic form.
    🔗

    Theorem 21. Theorem.

    If \(A\) is a symmetric matrix with eigenvalues \(\lambda_i\text{,}\) then \(Q = \vec x^{\,T} A \vec x\) is
    🔗
    • positive definite when all eigenvalues are positive
      🔗
      🔗
    • positive semidefinite when all eigenvalues are non-negative
      🔗
      🔗
    • negative definite when all eigenvalues are negative
      🔗
      🔗
    • negative semidefinite when all eigenvalues are non-positive
      🔗
      🔗
    • indefinite when at least one eigenvalue is negative and at least one eigenvalue is positive
      🔗
      🔗
    🔗

    Proof.
    If \(A\) is symmetric, we can write \(A=PDP^T\) and set \(\vec y = P^T\vec x\text{,}\) so \(\vec x = P\vec y\text{,}\) and
    🔗
    \begin{align*} Q \amp= \vec x^{\,T} A\vec x\\ \amp= (P\vec y)^T A (P\vec y), \quad \text{using } \vec x = P\vec y\\ \amp= \vec y^{\,T} P^T A P\vec y\\ \amp= \vec y^{\,T} D\vec y , \quad \text{using } A = PDP^T\\ \amp= \sum \lambda_i y_i^2, \quad \text{because } D \text{ is diagonal} \end{align*}
    The entries of \(\vec y\) are \(y_i\text{.}\) Note that \(y_i^2\) is always non-negative, so for \(\vec y \ne 0\text{,}\) the sign of \(Q = \sum \lambda_i y_i^2\) will only depend on the values of \(\lambda_i\text{.}\) This implies, for example that when \(\lambda_i >0\) for all \(i\text{,}\) that \(Q\) is positive definite.
    🔗
    🔗
    🔗

    Subsection Example 3: Quadratic Forms and Eigenvalues

    Consider the quadratic form
    🔗
    \begin{equation*} Q = 4x^2 + 2xy - 2y^2 = \vec x^{\,T} A \vec x \end{equation*}
    The matrix of this quadratic form is
    🔗
    \begin{equation*} A = \begin{pmatrix} 4 \amp 1 \\ 1 \amp -2 \end{pmatrix} \end{equation*}
    Calculating its eigenvalues reveals that \(\lambda = 1 \pm \sqrt{10}\text{.}\) Because the eigenvalues are both positive and negative, our quadratic form is indefinite. Indeed, when we plot this surface using MATLAB, we see that the surface does have values that are both positive and negative.
    🔗
    🔗

    Subsection Summary

    In this section we explored geometric interpretations of the quadratic form
    🔗
    \begin{equation} Q = \vec x^{\,T} A \vec x\tag{18} \end{equation}
    where \(A \in \mathbb R^{2\times 2}\) is symmetric. Then the set of \(\vec x\) that satisfies this equation create a surface. The surface, \(Q\text{,}\) could have a minimum or maximum value that may or may not be unique. If all the eigenvalues of \(A\) are known, we have seen how we can characterize the extreme values of a quadratic form give by \(Q = \vec x^T A \vec x\text{.}\)
    🔗
    Those students who have encountered quadratic surfaces in a multivariable calculus course may have already seen the forms discussed in this section from a different perspective. In such a course students may also consider more general quadratic surfaces of the form
    🔗
    \begin{equation*} Q^2 = \vec x^T A \vec x \end{equation*}
    Such forms can be used to create ellipsoids, cylinders, and other useful shapes that are studied in calculus, but go beyond the scope of this course.
